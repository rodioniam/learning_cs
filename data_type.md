# Типы данных в C#
Для хранения любых данных в C# всегда создается определенный объект, который хранит их в памяти.
Исходя из типа данных данный объект может принимать те или иные значения, характерные для этого типа данных. Другими словами это переменные со своим типом данных, не как в Python где есть диманическая типизация.

Есть `числовые-целочисленные`, `числовые с плавающей точкой`, `символьные`, `логический (boolean)` и особый тип. Тут есть некоторая схожесть с SQL, так как тип численных данных определяет их максимальное\минимальное допустимое значение и занимаемый ими объем памяти в байтах.

### Числовые - целочисленные
| Тип | Название | Размер | Минимальное значение | Максимальное значение |
| --- | -------- | ------ | --------------------- | -------------------- |
| byte | Byte | 1 | 0 | 255 |
| sbyte | SByte | 1 | -128 | 127 |
| short | Int16 | 2 | -32768 | 32767 |
| ushort | UInt16 | 2 | 0 | 65535 |
| int | Int32 | 4 | -2147483648 | 2147483647 |
| uint | UInt32 | 4 |0 | 4294967295 |
| long | Int64 | 8 | очень много отрицательных | очень много положительных |
| ulong | UInt64 | 8 | 0 | еще больше положительных |

### Числовые с плавающей точкой
| Тип | Название | Размер | Минимальное значение | Максимальное значение |
| --- | -------- | ------ | --------------------- | -------------------- |
| float | Single | 4 | отрицательные | положительные |
| double | Double | 8 | больше отрицательных | больше положительных |
| decimal | Decimal | 16 | очень много отрицательных | очень много положительных |

### Символьные
| Тип | Название | Размер | Минимальное значение | Максимальное значение |
| --- | -------- | ------ | --------------------- | -------------------- |
| char | Char | 2 | нет | нет |
| string | String | N/A | N/A | N/A |

`char` может хранить любые символы, а `string` это коллекция `char`

### Логический тип
| Тип | Название | Размер | Минимальное значение | Максимальное значение |
| --- | -------- | ------ | --------------------- | -------------------- |
| bool | Boolean | 1 | False | True |

### Особый тип 
| Тип | Название | Размер | Минимальное значение | Максимальное значение |
| --- | -------- | ------ | --------------------- | -------------------- |
| object | Object | N/A | N/A | N/A |
| dynamic | N/A | N/A | N/A | N/A |

`object` - это базовый тип данных, можно сказать значение по умолчанию. Все остальные типы строятся на нем, он может хранить любые данные. `dynamic` практически тоже самое, только в отличие от `object` он может изменять свой тип на лету.


Колонка с названиями это названия из стандартной библиотеки классов `.NET`. Можно пользоваться любым из названий. Обычно используются названия из первой колонки.
