# Конвертация данных

## Конвертация строки, метод Convert

При совершении операций сложения строчных типов данных будет всегда происходить конкатенация строк - не будет сложения чисел, а просто их объединение.

Для этого нужно конвертировать данные в нужный тип с помощью класса `Convert`

Интересная особенность - если что либо складывается со строкой, то будет применена конкатенация.

Так же может понадобиться использовать форматер для чисел с плавающей точкой, так как в разных системах она может быть разной - `.` или `,`. При попытке конвертации числа строки с точкой в дробное число будет ошибка форматера. Для этого есть специальный класс который может заранее указывать как форматировать плавующую точку.

## Преобразование строки. Парсинг строк, методы Parse и TryParse

Метод `parse` вызывается у самих типов, работает он исключительно со строками

Так же есть метод `Tryparse` - он нужен в случаях, когда в строке могут находится не только циферные символы. При его использовании используется try...except техника. `TryParse` работает схожим образом, но не бросает исключения.

Для его использования сначало надо объявить переменную, в которую запишется результат попытки парсинга. Если парсинг не получился, то в переменную будет записан ноль, а программа не упадет от ошибки. Так как метод возвращает 0 - он может быть расценен как булевое значение `false`, поэтому данный метод стоит использовать в связке с if statement.
