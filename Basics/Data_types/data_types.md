## Стек (stack) и куча (heap)
Эти оба понятия относятся к оперативной памяти, но используется она в них по разному, для разных целей и имеет разный объем. Для стека используется малый объем, а для кучи большой. 

`Stack` - это небольшой объем памяти, который выделяется для каждого потока (default = 1mb). На данном этапе это каждый отдельный файл со скриптом, который я писал тут. Позволяет очень быстро размещать и очищать данные. Работает по принципу `last in - first out` - последняя задача или переменная, которая попала в стек, будет извлечина из него первой.

`Heap` - это нечто вроде склада в оперативной памяти. Объем может быть разным и зависит от аппаратной платформы, на которой запускается программа. Например, для 32 разрядных систем это около 1.5гб, а для 64 разрядных - до 8тб. Накладно выделять место под данные и более проблематично их очищать. Однако в C# есть `Garbage Collector` как и в Python. 

| Что нужно знать? | Value Types (значимые типы) | Reference Types (ссылочные типы) |
| ---------------- | --------------------------- | -------------------------------- |
| Где размещаются объекты?| Stack | Heap |
| Как отличить? | struct, enum (неявно унаследованы от System.ValueType) | class (может быть производным от любого другого типа, если только этот тип не назначен) |
| Когда прекращают существование? | Когда покидает контекст, в котором были определены | Когда объект подвергается сборке мусора |
| Поведение при передачи параметров и копировании | Переменные передаются по значению (копируются реальные данные) | Копируется ссылка, оригинал и копия ссылаются на один и тот же объект в `heap` = одни и те же данные|

## Null тип
Можно использовать только с ссылочными типами. Значение которое устанавливается по умолчанию для ссылочных типов данных это `null` - отсутствие данных или пустая ссылка.

### Оператор null-объединения -- `??` 
Позволяет устанавливать default значение для ссылочных типов данных.

### Оператор присваивания объединения со значением null -- `??=`
Ключевая разница это взаимодействие с левым операндом. Обычный `??` присвоит значение `null` и передаст дальше значение по умолчанию, НО в переменной останется `null`. Оператор `??=` присвоит именно значение по умолчанию в переменную, тоесть `null` там не будет.

### Оператор условного null -- `?.`
Ставится перед вызовом какого либо метода, например, `arr?.Sum()`. Если в переменной `arr` придет `null`, то из-за применения данного оператора метод `Sum` просто не сработает. Очень часто используется вместе с оператором `??` чтобы выводить default значение при получении `null`.


# Ключевое слово `ref`.
Ключевое слово ref в C# относится и к функциям (методам), и к типам данных, связывая их через концепцию управления памятью и передачи по ссылке.

Его основная задача состоит в том чтобы при необходимости передачи структурных типов данных не происходило копирование (с вытекающими моментами в виде удаления после выхода из области видимости и тд), а именно ссылка (как это происходит с сылочными типами данных). 

`ref` так же можно использовать и с ссылочными типами данных. Фишка в том, что при передаче в метод какого то ссылочного параметра создается вторая ссылка на этот же объект в памяти. И чтобы это избежать можно использовать `ref` - тогда по сути будет передана ссылка на ссылку - то-есть связь с объектом будет осуществляться по одной и той же ссылки, а не по копии ссылки.

В новых версиях `C#` `ref` еще можно использовать чтобы сделать из обычной переменной ссылочную - взаимодействовать через отдельную переменную с каким то объектом в памяти не напрямую, а по ссылке. Так же можно использовать и с `return` - возвращаемым типом данных
