## Стек (stack) и куча (heap)
Эти оба понятия относятся к оперативной памяти, но используется она в них по разному, для разных целей и имеет разный объем. Для стека используется малый объем, а для кучи большой. 

`Stack` - это небольшой объем памяти, который выделяется для каждого потока (default = 1mb). На данном этапе это каждый отдельный файл со скриптом, который я писал тут. Позволяет очень быстро размещать и очищать данные. Работает по принципу `last in - first out` - последняя задача или переменная, которая попала в стек, будет извлечина из него первой.

`Heap` - это нечто вроде склада в оперативной памяти. Объем может быть разным и зависит от аппаратной платформы, на которой запускается программа. Например, для 32 разрядных систем это около 1.5гб, а для 64 разрядных - до 8тб. Накладно выделять место под данные и более проблематично их очищать. Однако в C# есть `Garbage Collector` как и в Python. 

| Что нужно знать? | Value Types (значимые типы) | Reference Types (ссылочные типы) |
| ---------------- | --------------------------- | -------------------------------- |
| Где размещаются объекты?| Stack | Heap |
| Как отличить? | struct, enum (неявно унаследованы от System.ValueType) | class (может быть производным от любого другого типа, если только этот тип не назначен) |
| Когда прекращают существование? | Когда покидает контекст, в котором были определены | Когда объект подвергается сборке мусора |
| Поведение при передачи параметров и копировании | Переменные передаются по значению (копируются реальные данные) | Копируется ссылка, оригинал и копия ссылаются на один и тот же объект в `heap` = одни и те же данные|
