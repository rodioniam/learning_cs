# Массивы

## Одномерные массивы
Это коллекция данных одного типа. С# строго типизированный язык и поэтому тут не как в Python где в коллекциях могут быть данные разного типа.

При объявлении массива нужно указать его тип данных и выделить ему место в памяти - сколько элементов он сможет хранить. По умолчанию после выделения памяти записывает в себя 0 на все места - будет массив с нулями.

Индексация так же с 0. Методы массивов так же через точку после объекта.

## Примеры различных типовых задач с массивами
Тут про методы массивов - многие из них такие же как в Python. В курсе говорит что для использования методов нужно импортировать `using System.Linq`, но у меня работает и без импорта данного модуля.

Очень часто после использования метода я буду получать какой то объект, который надо конвертировать с нужный мне тип данных.

Так же можно использовать методы от класса Array и передавать в него массивы

## Двумерные массивы
Ну по понятию это классический двумерный массив - таблица. По использованию как в C#. При создании массива можно не указывать конкретное кол-во столбиков и строчек

### Вывод массива на консоль
При выводе многомерного массива можно использовать циклы. Метод `length` выводит количество всех элементов в массиве, а метод `GetLength` показывает кол-во элементов в какой то определенной плоскости массива.

## Зубчатые массивы (Jagged Arrays или Arrays of arrays)
Это массив, в котором кол-во элементов по оси X может быть разным - разная длина строк. По сути это массив, который хранит тип данных массив. При выделении памяти под каждый внутренний массив нужно выделять память отдельно.

## Многомерные массивы
Тут просто добавляются новые оси кординат, по сути все по классике. Для взаимодействия с элементами таких многомерных массивов нужно сначала указать слой (`Z`), а потом по классике координаты `Y` и `X`. На практике как обычно чаще всего максимум используют трех мерные массивы.
