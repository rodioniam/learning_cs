# Ключевые слова

## Ключевое слово `ref`.
Ключевое слово ref в C# относится и к функциям (методам), и к типам данных, связывая их через концепцию управления памятью и передачи по ссылке.

Его основная задача состоит в том чтобы при необходимости передачи структурных типов данных не происходило копирование (с вытекающими моментами в виде удаления после выхода из области видимости и тд), а именно ссылка (как это происходит с сылочными типами данных). 

`ref` так же можно использовать и с ссылочными типами данных. Фишка в том, что при передаче в метод какого то ссылочного параметра создается вторая ссылка на этот же объект в памяти. И чтобы это избежать можно использовать `ref` - тогда по сути будет передана ссылка на ссылку - то-есть связь с объектом будет осуществляться по одной и той же ссылки, а не по копии ссылки.

В новых версиях `C#` `ref` еще можно использовать чтобы сделать из обычной переменной ссылочную - взаимодействовать через отдельную переменную с каким то объектом в памяти не напрямую, а по ссылке. Так же можно использовать и с `return` - возвращаемым типом данных


## Ключевое слово `out`.
Работает практически так же как и `ref` - передавая параметр с этими ключевыми словами, они передаются по ссылке. Разница у них в том, что передавая переменную по ссылке через `ref` в метод, я не обязан внутри метода присваивать ей какое либо значение. Используя же `out` я обязан присвоить ей какое то значение.


## Ключевое слово `in`.
Так же передает параметр в метод по ссылке, но ведет себя как полная противоположность `out` - изменение значения данной переменной внутри метода недопустимо.


## Ключевое слово `params`.
Позволяет упростить и сократить способ передачи множества одинаковых параметров в метод. При написании метода создает массив из параметров и позволяет внутри метода при помощи, например, цикла взаимодействовать с ними. В методе `params` может быть только один и указывается после всех остальных аргументов. И в отличие от стандартных массивов, `params` массив может содержать много разных типов данных если использовать `object`.


## Ключевое слово `enum`.
Это список констант. По умолчанию это тип данных `int`, но тип можно задавать вручную. Чаще всего это нужно для оптимизации работы с памятью. Стоит помнить, что публичность `enum` и метода для него должна быть одинаковой.


## Ключевое слово `this`
Упрощает использование параметров и методов у которых одинаковые названия. Позволяет указывать на конкретный параметр или переменную, с которой нужно что то сделать. Он указывает на текущий экземпляр класса\метода и тд.

Так же упрощает перегрузку конструктора класса. 

`this` не может быть использован в объектах с ключевым словом `static`.
