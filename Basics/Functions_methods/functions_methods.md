# Функции\методы
Синтаксис выглядит вот так:

модификаторы тип_возвращаемого_значения название_функции\метода(параметры)

{
    тело фунции\метода

    return
}

Функция или метод в `C#` это неразрывные понятия, так как никакая функция не может существовать без класса, а функции, которые принадлежат классу принято называть методами.

### Объявление класса
- `public` - класс доступен из любого места проекта.
- `static` - нельзя создать объект этого класса (new Functions() не сработает).
- `class` - объявление класса.
- `Functions` - имя класса.

### Объявление метода класса
- `public` - метод доступен извне.
- `static` - метод принадлежит самому классу, а не объекту.
- `void` - метод ничего не возвращает.
- `Function1` - имя метода.
- `()` - параметры метода (пока их нет).

Прикольная особенность `C#` - не обязательно сначала писать функции, чтобы потом их использовать (как в `Python`). Вызов метода и его объявление никак не зависят от положения кода на странице - не важно что выше, что ниже и тп.

Перегрузка методов - это изменение работы метода в зависимости от передаваемых в него параметров\аргументов. Пока выглядит так, что в `C#` можно написать несколько одинаковых методов по названию, но с разным количеством требуемых аргументов. При вызове данного метода будет выбран тот, который поддерживает передаваемое кол-во аргументов. Перегрузка методов может появится и просто из-за разного входного/выходного типа данных у разных реализаций одного и того же метода.

## Области видимости
В C# области видимости разграничиваются {} (наверное).


## Необязательные параметры для методов.
Это параметры, которые имеют значение по умолчанию и объявляются они при помощи `type name = значение`


## Именованные параметры методов.
Чтобы не зависеть от порядка передаваемых переменных. Передается через `a:2`.


# Рекурсии
Вызов методом самого себя. Рекурсия ограничена размером стэка. Каждый новый вызов метода будет занимать место в стэке. Всегда нужно предусматривать способ выхода из рекурсии.
