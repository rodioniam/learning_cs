# Делегаты
Делегат - это тип данных, который может хранить ссылку на метод. Нельзя в любой делегат присвоить любой метод - строгая типизация не позволит. В `C#` уже есть встроенные делегаты, которые повсеместно используются. Самый используемый делегат - `Func`. Это самый гибкий\обобщенный делегат, так как может работать с `generics`.

Типичный пример примерения делегата - это использование его как параметра для методов. Это поможет решить проблему когда уже есть какой то метод и в нем есть какой то момент, который может выполняться по разному. Чтобы не делать перегрузку метода или не писать несколько методов, которые будут отличаться одной строчкой кода можно в качестве аргумента передавать в него делегат - при вызове этого метода в аргумент будет присваиваться нужный метод.

Можно писать свои собственные делегаты.

# Лямбда выражения
По сути то же самое что в `Python` - функция в одну строчку. В `C#` использование делегатов практически всегда сопровождается использованием лямбда выражений. Это способ быстро, прямо на месте описать какой то метод анонимно.

Первый способ - просто написать метод целиков в параметрах метода. Этот вариант считается устаревшим, но использовать его можно.
