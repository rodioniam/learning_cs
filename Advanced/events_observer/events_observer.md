# События и паттерн "Наблюдатель"
`Event` или события это по своей сути обертка для делегатов, нужная для инкапсуляции. И еще `event` это один из способов реализации паттерна `observer`. Этот паттерн позволяет написать код слабо связанный между собой, участки кода друг от друге не знали и взаимодействуют они через определенный участок кода.

Наблюдатели подписываются на делегат, который вызывается в методе, который всех наблюдателей связывает.

Использование `event` ограничивает работу с делегатом только подписками и отписками
