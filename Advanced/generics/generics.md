# Обобщения - Generics
Это способ писать код так, чтобы он мог работать с различными типами данных, сохранив при этом строгую типизацию `C#`. Одним из плюсов генериков является возможность избегать процессов упаковки и распаковки. Так же обобщения позволяют легче повторно использовать код - при правильном использовании можно написать код так, что он будет работать сразу с несколькими типами данных и не придется писать отдельную функцию под каждый тип данных.

Если метод принимает один generic тип, значит он не может в качестве аргументов принимать два разных типа - они должны быть одного типа, который будет воспринят как generic тип для метода.

Под капотом однако никакой магии не происходит - каждый раз при компиляции кода генерируется метод, который соответствует передаваемым в него типам аргументов.
