# Итератор и итерируемый объект в `C#`
Происходит наследование от интерфейсов `IEnumerator` (для итератора) и `IEnumerable` (для итерируемого объекта).

У итерируемого объекта должны быть реализованы методы `GetEnumerator` и его non-generic версия. При использовании ключевого слова `yield` написание отдельного класса итератора не нужно.

Но если же без использования `yield`, то у итератора нужно реализовать методы `Current` (+ non-generic версия), `MoveNext`, `Reset` и `Dispose`.

# Использование ключевого слова `yield`
По своей сути то же самое что и в `Python`. Только в `C#` используется вместе с `return` => `yield return something`. Одним из частых сценариев использования `yield` это упрощение написания итератора. 

Под капотом `yield` генерирует `state machine`. В части случаев это `switch...case` конструкция, где для каждого момента `yield` генерируется свой `case`. `state` при этом хранит счетчик, который не позволяет второй раз попасть в какой то из отработавших `case`.

Еще одной ключевой ролью `yield` является оптимизация программы - оно играет гигантскую роль в экономии памяти. Так как `yield` помнит где он остановился и выполняет только ту часть которая ему приписана, он использует только тот объем оперативной памяти, который ему необходим для работы с данным объектом. После работы сборщик мусора будет очищать память.

## `yield` + `break`
Прерывает код в `state machine` без возврата какого либо значения. В этом случае в коде генерируется `return false` в `case`, который приходится на `yield break`.
