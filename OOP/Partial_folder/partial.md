# Partial
Использование этого ключевого слова в классах позволяет разнести его код по разным файлам. На практике применяется довольно редко. 

## Partial class
Для реализации частичного класса нужно использовать ключевое слово `partial` и одинаковое название класса в разных файлах. Должны быть в одном `namespace`. 

## Partial methods
По сути работает так же как и с классами, только на уровне методов. Части такого метода должны быть внутри одного класса, то-есть нелья написать часть метода в одном файле, а другую часть в другом файле (только если класс тоже не является `partial`). Если частичные классы еше и используются иногда, то вот написание частичных методов вообще не понятно зачем нужно.
