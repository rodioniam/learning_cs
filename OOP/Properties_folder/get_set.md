# Свойства Get и Set
Это один из инструментов реализации инкапсуляции классов - предоставление доступа к приватным переменным класса со специальной логикой.

На практике там не просто обычное прямое присвоение или получение, а какая то скрытая логика, например, какая то проверка на допустимость присвоения данного значения этой приватной переменной.

## Свойство
Это более удобный способ создания get и set методов. В коде это будет выглядеть так, что происходит обращение к переменной напрямую, но на самом деле происходит обращение через кастомные `get` и `set` свойства. 

Есть возможность использовать только один из аксессоров, нужно просто удалить блок с аксессором. Так же аксессоры могут быть приватными или публичными. Если они приватные, то их работа ограничена областью видимости класса.

## Автоматические свойства
Это когда не нужна какая то особая логика для доступа к переменной.
